# Simple Interest Calculator

A simple calculator that calculates simple interest based on the principal amount, interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal = Initial amount of money
- Rate = Annual interest rate
- Time = Time period in years

## Example

If the principal is 1000, the interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100

## Features

- Calculates simple interest
- Easy to use
- Uses the standard simple-interest formula
